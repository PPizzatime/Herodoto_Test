Herodoto Project Documentation

Last Updated: September 2026

1. Executive Summary

Herodoto is an AI-guided cultural travel platform. It offers a mobile app for consumers to experience interactive, audio-guided tours based on their geographic location, and a web portal for internal operations (admin/managers).

2. Current Architecture

Frontend (Mobile) Implemented

  • Framework: React Native with Expo (runs on iOS, Android, and Web).
  • Features: Location-based tour sorting, interactive maps, text-to-speech (TTS) audio playback, offline-ready UI components.
  • Login: Autofill development buttons for fast testing, secured behind Supabase Auth.

Frontend (Web Office) Implemented

  • Framework: Next.js (React)
  • Features: Admin dashboard, organization chart manipulation (restricted by RBAC), content management workflows.

Backend Implemented

  • Platform: Supabase (PostgreSQL, GoTrue Auth, Edge Functions)
  • Security: Row Level Security (RLS) policies enforcing multi-tenant isolation.
  • Automation: Postgres Triggers automatically assign correct RBAC roles (Admin, Manager, Employee) when a user creates an account with specific email domains (@herodoto.art).
